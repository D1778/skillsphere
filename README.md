# 🌐 SkillSphere

**SkillSphere** is an AI-powered Career Intelligence Platform that helps candidates discover their real skills, identify skill gaps, generate personalized career roadmaps, and connect with relevant job opportunities — while giving companies a way to post jobs, discover talent, and evaluate candidates based on verified skills rather than traditional resumes.

The platform ships as two independent apps in one repo: a **React (Vite)** frontend and a **Node/Express + MongoDB** backend, connected over a REST API.

---

## ✨ Key Features

### For Candidates
- **Guided profile builder** — structured onboarding flow to capture skills, education, experience, links, and portfolio details.
- **AI-generated career roadmaps** — a 4-phase learning path (Foundational → Intermediate → Advanced → Mastery), generated by an LLM based on a target job role, with topics, projects, skills, resources, and time estimates for each phase.
- **GitHub-powered insights** — pulls public repo data to surface real, verifiable coding activity.
- **Job discovery** — browse open roles, with an AI-ranked "Recommended for you" list based on the candidate's skill profile.
- **Personal dashboard** — an at-a-glance view of profile completeness, roadmap progress, and recommended jobs.
- **In-app notifications** for application updates and platform activity.
- **AI assistant widget** — a floating chatbot shell present across candidate and company views (currently front-end only; see [Chatbot](#-chatbot) below).

### For Companies
- **Company profile & branding** — logo, description, and social links.
- **Job postings** — create, edit, and manage listings with a rich-text (WYSIWYG) description editor.
- **Candidate discovery** — browse and filter candidates by skills.
- **Applicant tracking** — review applications per job posting.
- **AI-assisted recommendations** — candidate suggestions surfaced on the company dashboard, generated via a dedicated LLM quota separate from the candidate-side features.

### Platform-wide
- **Secure authentication** — email/password with OTP-based email verification, JWT access + refresh token rotation, and password reset via email.
- **Dual theme system** — full Light/Dark mode with a shared CSS variable design system, glassmorphism cards, and ambient section-by-section glow lighting.
- **Responsive, animated UI** — scroll-triggered reveal animations (`AnimatedSection`) and a custom Armillary Sphere logo/icon system used consistently across nav, footer, and chatbot.
- **File uploads** — profile photos, company logos, and certificates, served statically from the backend.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (required for native `fetch` used by backend AI/GitHub services)
- npm
- A MongoDB instance (local or Atlas)
- API keys/accounts for: Firebase, Groq, Google Gemini, GitHub (personal access token), and an SMTP provider or Resend (for email)

### 1. Clone & install

```bash
git clone <repository-url>
cd skillsphere

# Frontend deps
npm install

# Backend deps
cd backend
npm install
cd ..
```

### 2. Configure environment variables

**Backend** — create `backend/.env`:

```env
# Server
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173

# Database
MONGO_URI=mongodb://localhost:27017/skillsphere

# JWT
JWT_SECRET=your_jwt_secret
JWT_EXPIRES_IN=15m
JWT_REFRESH_SECRET=your_refresh_secret
JWT_REFRESH_EXPIRES_IN=7d

# OTP
OTP_EXPIRES_MINUTES=10

# Email (SMTP and/or Resend, depending on your notification.service.js setup)
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your_smtp_user
SMTP_PASS=your_smtp_pass
SMTP_ALLOW_INSECURE_TLS=false
EMAIL_FROM="SkillSphere <no-reply@example.com>"

# Firebase Admin
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
FIREBASE_PRIVATE_KEY="your_firebase_private_key"

# AI providers
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=llama-3.3-70b-versatile

GEMINI_API_KEY=your_gemini_api_key                      # candidate "recommended jobs"
GEMINI_API_COMPANY_DASHBOARD=your_gemini_api_key_2       # company dashboard AI recommendations
GEMINI_MODEL=gemini-2.0-flash

# GitHub insights
GITHUB_TOKEN=your_github_personal_access_token

# Dashboard caching
DASHBOARD_RECOMMENDATION_TTL_HOURS=6
```

**Frontend** — create `.env` in the project root:

```env
VITE_API_URL=http://localhost:5000
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_APP_ID=...
```

> Match the exact Firebase variable names to whatever `src/config/firebase.js` expects in your setup.

### 3. Run the app

```bash
# Terminal 1 — backend (http://localhost:5000)
cd backend
npm run dev

# Terminal 2 — frontend (http://localhost:5173)
npm run dev
```

Visit `http://localhost:5173` and check `http://localhost:5000/health` to confirm the API is up.

## 🔌 API Overview

All endpoints are mounted under `/api`, with a `/health` check at the root.

| Route prefix | Responsibility |
|---|---|
| `/api/auth` | Signup, signin, OTP verification, password reset, token refresh |
| `/api/user` | User account data |
| `/api/profile` | Candidate profile CRUD |
| `/api/github` | GitHub-derived candidate insights |
| `/api/roadmap` | AI roadmap generation & current/previous swap |
| `/api/jobs` | Job postings, applications, AI-recommended jobs |
| `/api/candidates` | Candidate discovery for companies |
| `/api/dashboard` | Aggregated dashboard data + AI recommendations |
| `/api/notifications` | In-app notifications |

Auth routes have a dedicated rate limiter (30 req / 15 min); all other routes share a generous global limiter (600 req / 15 min) sized as a DDoS backstop rather than a per-feature throttle.

## 🎨 Design System

Full details on the visual architecture, component-by-component breakdown, and CSS/theme system are documented in [`SkillSphere_Documentation.md`](./SkillSphere_Documentation.md) (also available as a PDF). Highlights:

- CSS custom properties drive every color (`--bg-page`, `--text-primary`, `--bg-card`, `--border-card`, `--glow-1` … `--glow-5`), toggled instantly between dark (default) and `[data-theme="light"]`.
- `.card-glass` utility provides the shared glassmorphism look (blur, translucent borders, hover states) used across all cards.
- `AnimatedSection` wraps page sections with `IntersectionObserver`-driven fade/slide-in reveals.
- A custom Armillary Sphere SVG logo is reused across the navbar, footer, and chatbot trigger for brand consistency.

## 🗺️ Roadmap Generation Logic

Career roadmaps are generated by an LLM (via Groq) using a system prompt that always produces exactly four phases — **Foundational, Intermediate, Advanced, Mastery** — each with topics, projects, skills, resources, and time estimates, tailored to whatever target job role the candidate specifies. Each user retains at most two roadmaps at a time: `current` (active) and `previous` (the one before it), with a swap operation that acts like an undo/redo between the two.

## 🔒 Security Notes

- Passwords hashed with bcrypt; JWT access/refresh token rotation for sessions.
- Helmet is configured with `crossOriginResourcePolicy: 'cross-origin'` specifically so that uploaded images (profile photos, logos, certificates) served from the backend can be rendered on the frontend's separate origin — all other Helmet protections remain intact.
- Separate, tighter rate limiting on authentication routes than the rest of the API.
- Email verification via OTP on signup, and a token-based password reset flow.
